Status: **approved** — reviewer gpt-6.1-sol, verdict APPROVE, 2026-10-18 (r1 REVISE 11 findings,
r2 APPROVE; two P3 wording notes applied). Recorded at HEAD `4052428`. The register file is hash-pinned

What this is: for each artifact class, the store that wins as the code exists **now**. Where the
code differs from the specs, the difference is under Gaps and is not resolved here. Inputs:
[register v2](funda-blueprint-implementation-decision-register-v2.md) B-03 (v1 is superseded),
consolidated review §5.2, the [data spec](../specs/2026-10-11-canonical-financial-data-and-cross-source-comparison.md)

(`docs/specs/equity-os-s10-source-of-truth-evidence-retention.md`) is still a DRAFT and is not adopted.

Rules for every row. All tables are in schema `eqos`. "Append-only" means the
`eqos.reject_mutation()` triggers (`migrations/0001_evidence.sql`) refuse UPDATE, DELETE and
TRUNCATE, and the runtime role has only SELECT and INSERT; exceptions are named in the row.
Roles: **runtime** (drafts, content), **panel** and **owner** (decisions; the trigger sets
`decider`, `migrations/0012_report_ledger.sql`), **purge** (`eqos_purge`: retention deletes and
tombstones, 0028/0029), **migrator** (schema), **reader**. A derivative never accepts a canonical
write; if it disagrees with its authority, it is wrong and is regenerated.
