**Goal:** storage scales with coverage: every capture has a retention class; a dry-run lists
exactly the eligible blobs; an explicit, lock-guarded, crash-safe purge deletes them, tombstones
vendor payload and keeps outcomes; an expired exchange original restores only by a hash-matched
re-fetch; replay over expired vendor readings reports `ORIGINAL_EXPIRED`; backup and restore
never resurrect expired bytes, and a vendor licence end purges that vendor's material.
**Out of scope:** scheduled purge (P5); retention exception contracts and physical memory removal;
vendor blob compression; off-machine backups; backfilling addresses of pre-D9 exchange captures
(they stay `KEEP`, R14); deleting operator input files outside the snapshot store, and set copies
outside the backup directory (Risks); automatic re-ingest after a re-fetch mismatch; D8
shareholding intake; any change to a file whose content an extractor pin hashes (R13).
**Constraints:**
- Migrations forward-only; `0001`–`0026` immutable; D9 adds `0027`–`0030`.
- Approved amendment records, frozen manifests, `record.json` files and `capture_refs` rows are
  never rewritten. The only in-place change to evidence rows is the purge role's vendor
  tombstone, which ledger §6 item 4 authorises.
- The runtime role still cannot delete; only `eqos_purge` purges, and only through the purge path.
- Fetchers, purge crash points and reviewer calls are the only mocks; no network in tests.
- Manifest values come from a throwaway `scratchpad/` aid that never imports `fundamentals`.
- Never open, grep or print `stage4_holdout.yaml`, `stage4_manifest.yaml`, `data/holdout/` or
  `data/raw/onboarding/`; no code path or test added here reads them (R4).
- Strict mypy, ruff, frozen Pydantic, enums, structlog; every module traces to a stage
  acceptance or a verification case; 800-line cap per file (File map).

## Rulings (proposed; Sol approves with the plan)

- **R1 Paths and dependency direction.** Roadmap `0009_retention.sql` → `0027_retention_classes`
  (D9.2), `0028_retention_protocol` (D9.4), `0029_retention_purge` (D9.5), `0030_retention_refetch`
  (D9.6). D9.1 does **not** extend the digest-pinned `2026-10-12-report-ledger.md`; new records
  `docs/blueprint/amendments/2026-10-12-retention-replay.md` and
  `docs/blueprint/amendments/2026-10-12-a05-derived-amounts.md`. New retention imports:
  `contracts/retention.py` ← `pg/retention_io.py` (locks, authority files), `pg/backup.py` ←
  `evidence/capture_retention.py`, `retention/*` ← `api/*`. `pg` gains no import of `retention` or
  `evidence` (its existing `compare.run` import stays): restore takes purge-first and
  `retention.purge` takes the final backup as injected callables, composed in `api/db_cli.py`,
  `api/retention_cli.py`. New `compare` code imports only `contracts`. The orchestrator edits the
  roadmap row when recording this plan.
- **R2 Classes.** In SQL: `eqos.base_class(source_id, surface)` → `VENDOR` for every surface of a
  vendor source (`eqos.is_vendor_source`: `screener`, `screener-subscriber`, `tijori`, `upstox`)
  except Upstox `instruments` (`IDENTITY`); `IDENTITY` for non-vendor identity surfaces (NSE
  `EQUITY_L` and listings, BSE peer search, SHP listing); `EXCHANGE_REFETCHABLE` for
  `NSE_XBRL_INSTANCE`, `NSE_RESULTS_PDF`, `NSE_TRANSCRIPT_PDF`, `NSE_SHP_XBRL`; `COVERED` for any
  other non-vendor original; else `UNCLASSIFIED`. An `AFTER INSERT` trigger on `capture_refs`
  writes the class row (cause `INTAKE`); a second class row is refused. Pre-D9 captures classify
  once through `eqos.classify_existing()` (`fundamentals retention classify`, cause `ONE_OFF`);
  purge and dry-run refuse while any is unclassified. **Coverage (P3) is derived:** an
  `EXCHANGE_REFETCHABLE` capture is effectively `COVERED` when a linked entity
  (`eqos.capture_entities`) has an `ADD` not followed by a `REMOVE` before its registration.
  `eqos.retention_limited` is a view: each ADD × the entity's `VENDOR`/`IDENTITY` captures
  registered before it.
- **R3 Class rule, then source ceiling.** Vendor-bounded sources (`is_vendor_source`): four
  quarters from registration, extended only by open queue items, never past a licence end. Upstox
  (diagnostic and identity surfaces, `contracts/source_catalog.py:284-298`) may retain only "what
  an open investigation needs and no more", instrument files included
  (`upstox-rights-record.md:145-148,172,259`): its instrument lists are `IDENTITY` with that
  ceiling, and an identity event may reference one without extending it. Non-vendor sources have
  no ceiling (rights decision 004). Beyond-authority writes are refused at the database (RP3c, d);
  supports, onboarding outcomes and identity events on vendor captures are accepted and do not
  extend them. One test pins `is_vendor_source` to the sources of `INDEPENDENT_VENDOR`/`DIAGNOSTIC`
  catalog surfaces.
- **R4 Citation graph.** Roots and edges the hold query follows: report versions →
  `numeric_claims` (`0012:56-118`: quote capture; interpretation; calculation trace →
  `calculation_trace_operands` recursively; fact origin → legacy binding or `fact_admissions`
  `0011:4-18`); `COMPARISON` claim → `pair_outcomes` → `result_source_values` → interpretation or
  trace; `report_sections.body` markers `{{s:<capture>|<anchor>}}` (`ledger/numeral_scan.py:18`,
  resolved from bytes, `ledger/citations.py:241-256`); memory items and supports (`0016:27-39`);
  queue items and dispositions (`queue_item_inputs`, `queue_item_traces` `0008:4`;
  `OPEN_QUEUE_ITEM` when undisposed, `compare/queue.py:179-196`); legacy bindings
  (`0010:98-106`); identity events, onboarding records, namespace verifications through
  `evidence_input_captures` (`0001:36-41`, `0022:21-56`); qualification fixture sets
  (`config/mappings/**`, e.g. `xbrl/v3/in_bse_fin.yaml:92-95`); frozen manifest inputs
  (`config/retention/holds.yaml`, public manifests only; `stage4_manifest.yaml` excluded by name,
  never read; a test pins the list to the public `*_manifest.yaml` glob). Interpretations close
  over `interpretation_operands`, `interpretation_condition_evidence` and `construction_traces`
  (`0007:4`) down to occurrences. Run manifests and outcomes never hold. Edges that **need
  bytes**: `SOURCE_QUOTE` claims, location markers, legacy bindings.
- **R5 Eligibility** (pure), in order: licence end reached → `ELIGIBLE(since=licence end)`, holds
  notwithstanding; effective `COVERED` → `KEEP`; relevant holds → `HELD(reasons)` (any root for
  non-vendor-bounded sources, open queue items only for vendor-bounded, R3); then the anchor:
  `EXCHANGE_REFETCHABLE` = verification time, `KEEP` without an address; `VENDOR`/`IDENTITY` =
  registration. No anchor or `now` < anchor + window → `KEEP`; else `ELIGIBLE(since)`, reason
  `CATALOG_CEILING` when R3 set a hold aside. Windows: three calendar months (P4), four quarters,
  clamped to month end. **Verified** = the earliest `COMPLETE` run with a `SELECTED` `PACKAGE`
  input for the capture's package and no undisposed queue item on that package; time = the later
  of its `created_at` and the last disposition. `RESTORED` is evaluated like `RETAINED`. A
  **blob** `(source_id, blob_sha256)` over non-`EXPIRED` captures is eligible only when every user
  is, `since` the latest. `now` = `eqos.store_now()`; tests advance `eqos.store_clock_us` as owner;
  no production as-of flag.
- **R6 Retention protocol (RP).** Stated once; tasks and cases cite it by number.
  - **RP1 Lock.** Advisory key `eqos.retention_lock_key()`. Purge holds it exclusive at session
    level on a dedicated, non-pooled connection from the step-2 recheck through run close
    (recovery the same); backup holds it shared at session level from before its snapshot export
    through archive verification; everything else shared at transaction level through
    `eqos.retention_shared()`, which refuses while an intent is `PURGE_PENDING` or a run is open
    (naming `fundamentals retention purge`), then applies RP2. No isolation exception, no flag.
  - **RP2 Stale snapshot.** Sequence `eqos.retention_epoch` (`CACHE 1 NO CYCLE`; `USAGE` for
    `eqos_purge` only). Each purge commits a `purge_runs` row with `nextval` in its first
    transaction under the exclusive lock. `retention_shared()` is `VOLATILE` and, after the lock,
    issues fresh queries comparing `pg_sequence_last_value` (not MVCC) with the greatest
    `purge_runs.epoch` its snapshot sees by `IS NOT DISTINCT FROM` (both NULL before any purge).
    Unequal → `STALE_SNAPSHOT` with SQLSTATE `40001`, which the existing handlers retry. A waiting
    READ COMMITTED statement sees the purge commit and passes; REPEATABLE READ and SERIALIZABLE
    pass only with a snapshot after every purge. A rolled-back `nextval` fails closed until the
    next purge commits.
  - **RP3 Database boundary.** `eqos.retention_guard()` (`a0_retention_guard`, `BEFORE INSERT FOR
    EACH ROW`) on every R4 edge table plus `capture_refs`, watchlist `ADD`s, and the payload tables
    `occurrences`, `interpretations`, `interpretation_operands`,
    `interpretation_condition_evidence`, `construction_traces`, `calculation_trace_operands`,
    `result_source_values`, `run_inputs`, `acquisition_attempts`, `package_members`. It calls
    `retention_shared()`, resolves the row's captures and refuses (a) a payload row on a capture
    not `RETAINED`/`RESTORED` and (b) a byte-needing edge to one → `ORIGINAL_EXPIRED`; (c) any row
    on a source with a `licence_ends` row and (d) a `SOURCE_QUOTE` on a vendor capture →
    `BEYOND_AUTHORITY`. Other edges to expired captures proceed (ledger §5). It never reads
    `store_now()`.
  - **RP4 Store boundary.** (a) A marker `<root>/.retention/licence-ended/<source>`, written under
    the flock, makes `put_capture`, `get_capture` and `read_capture_verified` for that source raise
    `LicenceEndedError`. The one open path is `SnapshotStore.read_record(source, surface,
    request_key, capture_id, expected_sha256)`: `record.json` bytes, refused unless their SHA-256
    equals `capture_refs.record_sha256`. (b) Purge holds the flock from its first step-3 unlink
    until step 4 commits. Order: database lock, then flock; store-only publishers take only the
    flock.
  - **RP5 Store inventory.** Step 3, under the flock, lists every blob in the store independently
    of the candidates. A blob whose hash no `capture_refs` row of its source names (standalone
    publication, interrupted publication's `.staging` link) is `UNREGISTERED`; a candidate blob
    with more links than registered body links is `UNKNOWN_LINK`, its intents cancelled. Both keep
    their bytes and make the purge `INCOMPLETE`, naming the blob with "register or remove it",
    exit 3, until resolved. A **licence-end** purge deletes every body file under the source's
    capture tree and its whole blob tree, registered or not, and keeps every `record.json`; a link
    from outside those trees refuses before any deletion (exit 2).
  - **RP6 Identity, not bytes.** `ORIGINAL_EXPIRED` concerns the capture row. Equal bytes acquired
    again are a new capture (ledger §6) that republishes the blob; the expired capture keeps no
    body. First-party SHA-256 reuse matches retained captures only.
  - **RP7 Byte readers** use `read_retained` (`EXPIRED`/`PURGE_PENDING` → `OriginalExpiredError`;
    missing body otherwise → `IntegrityError`).

- **R7 Tombstones (A-05).** Vendor payload is tombstoned **in place** (outcomes, queue and run
  inputs reference the rows). Task 1 audits every column and JSON path the three vendor adapters
  and their derived traces and result rows write; the A-05 record fixes the **redaction
  inventory**: kept = id, capture id, key columns, anchor location, states, `first_seen_at`;
  cleared = every value-bearing scalar (`occurrences.raw_value_text`, `raw_sign` (NOT NULL dropped
  in 0029), `interpretations.value/lower/upper`, value/bound/exact-text columns of vendor-derived
  traces and operands, `result_source_values.value/lower/upper` of vendor and diagnostic roles);
  JSON columns reduced to an allowlist (so `island_value` goes); `transform_trace` → `{}`;
  value-derived digests listed, any a constraint keeps stated as A-05 residual risk. Kept as
  outcomes: results, `pair_outcomes` (status, reason, triage, `difference`, `interval_gap`),
  adjustments, queue items, dispositions, `COMPARISON` claims. Only migrator-owned `SECURITY
  DEFINER` `eqos.tombstone_vendor_capture(capture)`, executable by `eqos_purge` for a
  `PURGE_PENDING` `VENDOR` capture, does it; a replacement mutation trigger allows `UPDATE` only
  under its transaction-local flag and only of inventory columns. `DELETE` stays refused.
- **R8 Purge steps and recovery** (ledger §5 steps 1–5). Reconcile licence ends (R11); candidates;
  **step 1**: probe up to `PROBE_SAMPLE = 3` eligible `EXCHANGE_REFETCHABLE` captures per source
  (lowest ids); a mismatch or fetch failure halts that source's exchange deletions with a HIGH
  probe row (R9). Exclusive lock; commit the run row with its epoch (RP2). **Recover:** an open
  run's intents without a `FENCE` event get one before any unlink; each `PURGE_PENDING` intent is
  cancelled if bytes are intact and it is no longer eligible, else goes through steps 3–4; a run
  with `EXPIRED` rows and no `COMPLETE` event gets one; **residue**: a body link of an `EXPIRED` or
  `PURGE_PENDING` capture, and a blob with no non-`EXPIRED` registered user and no unknown link,
  is deleted again; open runs complete step 5. **Step 2:** recheck; commit intents (exchange only
  from probe-matched sources); append `FENCE`. **Step 3** (flock, RP4b): RP5 inventory; per blob,
  unlink each registered body link, then the blob, fsyncing parents; missing = deleted.
  **Step 4**, one transaction, then release the flock: purge records (capture, class, reason, URL
  or null, blob hash, probe row or `NOT_REQUIRED`, `purged_at` from the store clock), `EXPIRED`,
  `VENDOR` tombstones; then append `COMPLETE`. **Step 5:** injected final backup on the purge
  connection (R12); sanitize (R11); remove `.deleting`/`.partial` remnants; close the run. A crash
  anywhere leaves the run open, blocking writers (RP1) until a rerun converges.
  `retention/purge.py` has one deletion routine (licence-end variant included) and one sanitize
  routine; restore reuses both.
- **R9 HIGH incidents.** `queue_items` need a run, key and pair (`0006:55-70`); a probe failure or
  re-fetch mismatch has none, so (as D6's `IDENTITY_CONFLICT`, `0022:43-56`) they are
  `severity = 'HIGH'` rows in `retention_probes`/`refetch_attempts`, surfaced by the view
  `eqos.retention_incidents`: a probe incident closes on a later matching probe for that source, a
  mismatch incident when that capture is `RESTORED`. The dry-run prints open incidents; a command
  creating one exits 3 (`SUCCESS_WITH_OPEN_HIGH`, `compare/run_models.py:66-72`). Ledger "queues a
  HIGH item" is amended to this in the retention-replay record.
- **R10 Re-fetch.** `fundamentals retention refetch --capture <id>` admits only an `EXPIRED`
  capture of a non-vendor-bounded source with an address (else `NOT_REFETCHABLE`), so licence-ended
  sources and Upstox instruments are refused. `Fetch = Callable[[str], bytes]` raises
  `FetchFailure(category, http_status)`. **Live adapter** `live_fetch` (exchange addresses, no
  credential): opens the URL with `NoRedirectHandler` and `REFETCH_TIMEOUT_SECONDS` and, inside the
  response context, reads through `read_bounded_capture` with `expected_bytes` from
  Content-Length; non-`COMPLETE` → `INCOMPLETE`, `HTTPError` → `HTTP_STATUS`, timeout → `TIMEOUT`,
  other `URLError`/`OSError` → `CONNECTION` (`live_transport` drops headers, so it is not used).
  **Transaction A**, before any store write: a `refetch_attempts` row (`MATCH`/`MISMATCH`/
  `FAILED`, category, status, fetched SHA-256 or null). **MATCH** → transaction B under
  `retention_shared()`: `SnapshotStore.relink` writes the blob and links it as the capture's body
  under the flock (never `record.json`), reads it back verified, commits `RESTORED` (same id and
  times); admission requires latest state `EXPIRED`, a non-vendor-bounded source and a `MATCH`
  attempt whose SHA-256 equals `capture_refs.blob_sha256`. **MISMATCH** (HIGH): the capture stays
  `EXPIRED`; the bytes become a new capture via `capture_registration`, request parameters naming
  the attempt id (invariant 13). **FAILED**: nothing published, exit 2. **Rerun**, before
  fetching: a `MISMATCH` attempt whose new capture exists → report, exit 3; a `MATCH` attempt
  whose relinked body verifies → transaction B only; else fetch, reusing the latest unfinished
  `MISMATCH` attempt when the fetched SHA-256 equals its own, otherwise a new attempt. A purge's
  residue step also removes an uncommitted relink.
- **R11 Authority files** beside the sets in the backup directory, never inside one:
  `licence-ends.json` and `expiry-journal.json`. Journal events are append-only with ids previous
  + 1: `FENCE` (run; each intent capture's source, surface, request key, capture id, blob and
  record SHA-256, URL) and `COMPLETE` (run; expired and cancelled ids; `purged_at`). One helper in
  `pg/retention_io.py` appends to either: flock `.retention-authority.lock`, read, append (dropping
  or renumbering refused), write temp, fsync, rename, fsync directory. **Expiries after
  watermark w:** for each run with an event above w, its `COMPLETE` expired ids or, without one,
  all its `FENCE` captures (an unresolved fence applies conservatively: they were eligible, and
  exchange ones probe-matched with an address). Restoration is not journaled; re-fetch is the only
  way back, a later backup's watermark excludes the earlier expiry, and an older set re-expires
  the capture (still re-fetchable). Licence ends are authoritative independently. **Sanitize:** a
  set in the backup directory archiving the body of a capture in its expiries after its watermark,
  or of a licence-ended source, is renamed `.<name>.deleting`, the directory fsynced, the tree
  removed. **Initialisation** only when `write_backup` publishes into a provably new location
  (both files absent, no other set or remnant, no `licence_ends` row and no `EXPIRED` capture);
  otherwise a missing or unreadable file refuses purge, backup, restore and licence-end, writing
  nothing. **Reconciliation** at the start of each: file licence ends missing from the database
  are inserted; a database licence end missing from the file refuses (rerun `licence-end`);
  journal gaps are R8 recovery's. **Licence end** (owner, vendor-bounded sources), each step
  idempotent: (1) marker (RP4a), (2) file append, (3) `licence_ends` row, (4) purge, holds
  notwithstanding. After (1) the source is blocked at the store; after (2) the next purge, backup
  or restore reconciles (3); a rerun finishes (4).
- **R12 Backup and restore.**
  - **Backup:** `write_backup` takes `session_shared`, refuses pending recovery and missing
    authority, and records `BackupManifest.journal_watermark` = the last event id (no fence or
    completion can be appended under the shared lock). It archives every `RETAINED`/`RESTORED`
    capture's record and body and every other capture's `record.json` through `read_record`
    (licence-ended sources included), lists expired captures in `BackupManifest.expired` (row,
    URL, purge record id), verifies, publishes, initialises authority if eligible. With
    `held=<purge connection>` it asserts that connection holds the exclusive lock and waives the
    pending-recovery refusal for that run only, once its `COMPLETE` exists. Absent schema → D2
    unchanged; refused backups write nothing (`test_backup_restore.py:193,204` hold).
  - **Restore** (test databases only): verify the set; absent schema → D2 path; schema older than
    `0030` → refuse (no production set exists; D2 cutover is owner-gated, `eqos-3zl`); read
    authority from `--backup-dir` (default the set's parent); create the target **closed from
    creation** (`ALLOW_CONNECTIONS false`, CONNECT revoked from PUBLIC, granted to migrator and
    purge group only, then connections allowed); `pg_restore`; copy archived retained captures and
    every record. **Phase 1**, before any mutation: D2 faithful check (counts, run ids, FKs,
    retained and expired-record hashes, expired list equals the dump's `EXPIRED` set).
    **Markers:** `mark_licence_ended` for every licence end in the file or dump, before
    purge-first and before access. **Purge-first** (injected, R8's routines): insert missing
